# Amazon Sales Analytics Dashboard

## Project Overview

An Excel-based sales analytics project designed to analyze Amazon India sales data and present key business metrics through an interactive dashboard.

## Tools Used

* Microsoft Excel
* PivotTables and PivotCharts
* Excel formulas
* Data cleaning and validation

## Dashboard KPIs

* Total Sales
* Total Profit
* Total Orders
* Profit Margin
* Units Sold
* Average Order Value

## Business Analysis

The dashboard analyzes:

* Sales and profit by payment method
* Sales and profit by fulfillment method
* State-wise sales, profit, and order volume
* Order status distribution, including delivered, shipped, returned, and cancelled orders
* Category-wise returns and cancellations

## Key Skills Demonstrated

* Data organization and validation
* KPI calculation
* PivotTable-based analysis
* Data visualization
* Business performance reporting


## Note

This project was developed for data analytics practice and portfolio demonstration using an Amazon India sales dataset.
